# CLA-RFF
A Robust Intelligent System for Cross-Domain RF Fingerprinting in Heterogeneous Wireless Environments

# Data Availability Statement
The LoRa experiments in this work are based on the publicly available OSU LoRa RF fingerprinting dataset cited in the manuscript. The 5G NR dataset was collected in a real-world commercial cellular environment and is subject to confidentiality and data-use restrictions; therefore, the raw 5G NR IQ recordings cannot be publicly released or redistributed. To support reproducibility within this constraint, the manuscript provides detailed descriptions of the device population, acquisition configuration, session organization, sample scale, data partitioning, and evaluation protocol.
